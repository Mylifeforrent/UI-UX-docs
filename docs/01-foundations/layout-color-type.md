# 布局、色彩与字体

## 布局

先建立容器、列、间距和对齐规则，再摆组件。企业 Web 通常需要稳定的侧栏、顶栏、内容区和操作区；不要用随机 margin 修补关系。

## 色彩

颜色应表达品牌、层级和状态。至少定义背景、正文、边框、主色、成功、警告、错误和信息色，并检查文字与背景的对比度。状态色不能只靠颜色传达。

## 字体

优先保证可读性和数字对齐。为标题、正文、辅助文字和数据定义有限的字号/行高组合；不要在同一页面混用多个无明确理由的字体。

详细约束应落入 [Design Token](../04-design-system/tokens.md)，这样设计和代码不会各自维护一份“差不多”的值。
