# Design System

Design System 是设计规则、组件、页面模式和代码实现之间的契约。它的价值是减少决策、限制漂移，并覆盖真实业务状态。

- [Design Token](tokens.md)：颜色、间距、字号、圆角、阴影、主题和迁移。
- [组件规范](components.md)：组件 API、状态、键盘行为、可访问性和边界。
- [页面模式](patterns.md)：列表、详情、创建、审批和异常流程的固定行为。
- [设计到代码](design-to-code.md)：让 Figma 和 React/Vue 使用同一套语义。

推荐顺序：先定义 Token，再定义组件和模式，最后建立 Figma 到代码的映射。不要从一张未命名截图直接生成整页。
