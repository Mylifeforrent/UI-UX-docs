# 页面模式

页面模式是可以跨业务复用的完整结构，而不是单个组件。固定行为应保持一致，业务差异放在配置和数据里。

| 模式 | 固定行为 | 可配置区域 |
| --- | --- | --- |
| 列表 | 标题、筛选、结果摘要、主内容、分页和状态 | 列、筛选项、批量动作 |
| 详情 | 摘要、属性、关联数据、时间线和返回 | 字段分组、关联对象、危险动作 |
| 创建/编辑 | 分组字段、校验、草稿、提交反馈、离开保护 | 字段、默认值、校验规则 |
| 审批 | 待处理列表、责任人、意见、确认、审计反馈 | 状态、审批动作、风险信息 |
| 监控 | 指标、趋势、异常、筛选和钻取 | 指标、时间范围、图表类型 |

## 列表到详情

列表通过 URL 保存筛选、排序和分页；打开详情后返回，恢复列表上下文。详情中的危险动作必须显示权限、影响和审计反馈，不能只依赖一个红色按钮。

## 复用边界

复用“行为和布局关系”，不要复用导致语义不清的万能组件。每个模式都应在 [页面清单](../templates/page-inventory.md) 中声明数据依赖和状态，在 [设计评审](../templates/design-review.md) 中记录偏离标准模式的理由。
