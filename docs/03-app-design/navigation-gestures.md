# 导航与手势

导航要让用户知道“我在哪里、回去会到哪里、离开会不会丢数据”。手势只能加速操作，不能成为唯一入口。

## 返回栈

```text
通知 → 待审批列表 → 订单详情 → 驳回意见
返回：订单详情 → 待审批列表 → 通知/上一来源
```

从通知深链进入详情后，返回应回到通知上下文或明确的任务列表；不要无条件把用户送到首页。打开全屏表单时，系统返回和页面返回都应触发未保存保护。

## 手势规则

- 左右滑动用于切换同级内容时，必须保留按钮或分页替代方案。
- 滑动删除、长按和拖拽不能作为唯一操作；危险动作要有确认和撤销。
- 抽屉、横向滚动表格和系统边缘返回要避免手势冲突，保证可发现的关闭按钮。
- 键盘出现时，输入框和错误信息必须滚动到可见区域，主按钮不能被键盘遮挡。

## 反馈与幂等

审批按钮点击后立即进入提交中并禁止重复点击；成功显示状态和审计反馈，失败保留页面上下文并提供重试。离线时禁用无法可靠排队的危险动作，说明恢复网络后的操作方式。
