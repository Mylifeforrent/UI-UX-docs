# 响应式与页面状态

定义内容断点而不是设备清单。先回答内容在多窄的空间仍可读，再决定侧栏、表格和操作如何变化。

## 建议视口与变换

| 视口 | 布局策略 | 订单列表表现 |
| --- | --- | --- |
| 1440px | 固定内容最大宽度，侧栏展开 | 完整表格和批量工具栏 |
| 1024px | 侧栏可折叠，减少低频列 | 表格保留核心字段 |
| 768px | 筛选转抽屉，操作分组 | 横向滚动或摘要行 |
| 390px | 单列、全屏详情、底部固定主动作 | 订单号/客户/金额/状态摘要 |

使用稳定的网格、最小列宽和换行规则，禁止用随机负 margin 解决挤压。文字、按钮和错误文案的长度要在最窄容器中验证。

## 必备状态矩阵

| 状态 | 说明 | 用户下一步 | 不能做的事 |
| --- | --- | --- | --- |
| 加载 | 保留表头和布局，使用 Skeleton | 等待或取消 | 页面跳动、空白闪烁 |
| 空数据 | 尚未有任何订单 | 创建第一条或导入 | 只写“暂无数据” |
| 无结果 | 当前条件没有匹配项 | 清除筛选、修改条件 | 丢失筛选条件 |
| 错误 | 请求失败或超时 | 重试，保留已填内容 | 用成功样式掩盖失败 |
| 无权限 | 角色不能访问或执行 | 申请权限、返回 | 暴露敏感数据 |
| 部分数据 | 某些字段缺失或部分操作失败 | 查看详情、逐条重试 | 把缺失当 0、误报全量成功 |
| 成功 | 操作已被服务端确认 | 继续处理或查看记录 | 只闪过不可读的 Toast |

页面状态应和 [真实数据接入](../06-engineering-workflow/real-data-integration.md) 的 API 错误及权限语义保持一致，并在 [页面清单](../templates/page-inventory.md) 逐页勾选。
