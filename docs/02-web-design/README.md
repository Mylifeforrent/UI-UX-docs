# Web 设计

Web 是后端工程师最值得优先掌握的设计方向，尤其是企业后台、SaaS、数据工作台和内部运营系统。本目录是仓库主线，默认按下面顺序阅读。

1. [信息架构](information-architecture.md)：从角色、对象和任务整理导航、权限与 URL 状态。
2. [企业 SaaS 页面](enterprise-saas.md)：掌握列表、详情、创建/编辑、审批和监控骨架。
3. [表单与表格](forms-tables.md)：处理企业产品中最常见的录入、比较和批量操作。
4. [响应式与页面状态](responsive-states.md)：定义桌面到手机的变换和异常状态。

配套操作资产：[UI Brief](../templates/ui-brief.md)、[页面清单](../templates/page-inventory.md)、[组件清单](../templates/component-inventory.md)。完成后进入 [PRD 到原型](../06-engineering-workflow/prd-to-prototype.md)。
