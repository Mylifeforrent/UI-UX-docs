# 练习项目

通过两个递进项目建立能力，而不是只做零散组件。先完成 Web 工作台，再做移动端配套应用。

- [企业 Web 工作台](web-workbench.md)：用户、订单、审批或监控类系统，重点训练数据密集型界面、页面状态、API 和视觉验收。
- [移动端配套应用](mobile-companion.md)：从同一业务中提取高频任务，重点训练移动端信息架构、平台差异和中断恢复。

所有项目都使用 [UI Brief](../templates/ui-brief.md)、[页面清单](../templates/page-inventory.md)、[组件清单](../templates/component-inventory.md)、[设计评审](../templates/design-review.md) 和 [视觉验收](../templates/visual-acceptance.md)。
