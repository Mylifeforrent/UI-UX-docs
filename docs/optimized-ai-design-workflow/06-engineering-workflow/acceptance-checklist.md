# 交付验收清单

← 返回 [工程工作流](README.md) · [原型先行全流程主文档](../imports/prototype-first-workflow.md)

代码交付前逐条勾选。[视觉评审闭环](../imports/visual-review-loop.md) 只覆盖"看得见的"，这份清单覆盖完整交付质量。可复制到 PR 描述里当 checklist。

## 功能与状态

- [ ] 每个页面覆盖状态矩阵全部状态（默认/加载/空/无结果/错误/无权限/成功/部分失败）
- [ ] 空态、错误态有具体可行动文案，非占位符
- [ ] 危险/不可逆操作二次确认 + 强制理由 + 失败可逐条恢复
- [ ] 每条验收标准可测试并已通过（对照 PRD）

## 权限

- [ ] 各角色可见范围正确
- [ ] 无权限态按设计（只读/禁用/隐藏）实现
- [ ] 前端不作为唯一鉴权（后端有真实校验）

## 设计一致性

- [ ] 仅使用语义令牌，无硬编码颜色/魔法数字间距（见 [tokens](../04-design-system/tokens.md)）
- [ ] 组件名与 [组件清单](../templates/component-inventory.md) 一一对应，无同义新建组件
- [ ] 桌面 1440 / 手机 375 两档视口正确

## 无障碍（企业级必查）

- [ ] 键盘可完成主流程，Tab 顺序合理
- [ ] 焦点可见；对话框有焦点陷阱，Esc 可关
- [ ] 交互元素有可访问名称（aria-label 等）
- [ ] 文本与背景对比度达标（正文 ≥ 4.5:1）

## 工程质量

- [ ] 数据用 fixture 渲染，未硬接真实 API（原型阶段）
- [ ] 关键逻辑有测试
- [ ] 无 Make 原型代码直接进生产（代码是第 7 步重新生成的）

## 视觉验收

- [ ] 已完成 [视觉验收记录](../templates/visual-acceptance.md)，P0 状态两档均通过
