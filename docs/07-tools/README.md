# 工具定位

工具按工作流位置选择，不按“谁能一键生成最多代码”选择。请先读 [工具矩阵](tool-matrix.md)，再按数据敏感度、验证方式和生产边界做决定。

推荐组合：Figma/Figma Make 负责设计上下文和原型；[Figma MCP](../05-ai-design-workflow/figma-stack.md) 负责连接 Agent；Claude Code、Codex、Cursor 负责工程实现；UI UX Pro Max、Taste、Impeccable 属于 Coding Agent 的设计能力增强层；OpenPrototype、OpenUI 适合快速探索。

所有生成结果都必须回到 [Design System](../04-design-system/README.md)、[真实数据接入](../06-engineering-workflow/real-data-integration.md) 和 [验收清单](../06-engineering-workflow/acceptance-checklist.md) 验证。工具功能、价格、权限和数据政策可能变化，接入企业项目前以官方资料为准。
