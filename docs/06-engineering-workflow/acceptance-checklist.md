# 交付验收清单

每个检查项都要有结果和证据。证据可以是固定视口截图、录屏、键盘路径、自动化测试链接或接口响应，不接受“看起来没问题”。问题统一记录到 [视觉验收](../templates/visual-acceptance.md)。

## 视觉与布局

- [ ] 1440px、1024px、768px、390px 下容器、对齐线和主要操作稳定。
- [ ] 首屏 5 秒内能找到页面标题、主任务和主按钮。
- [ ] 标题、数据、辅助信息的层级清楚，没有多个模块争抢主视觉。
- [ ] 间距、颜色、字号来自 [Design Token](../04-design-system/tokens.md)，没有单页临时值。
- [ ] 长标题、长客户名、大金额、空字段和多语言文本不会溢出或遮挡。

## 交互与状态

- [ ] 默认、加载、空数据、无结果、错误、无权限、部分数据、成功状态都有实现。
- [ ] 筛选、排序、分页可以刷新和分享；返回列表时条件和滚动位置符合预期。
- [ ] 批量操作显示选中数量、确认、处理中、成功、部分失败和重试。
- [ ] 危险操作有明确对象、影响和可恢复路径，未保存内容离开时有保护。
- [ ] 对话框、抽屉、Toast 和表单错误都能说明发生了什么及下一步。

## 键盘与无障碍

- [ ] 主流程可只用键盘完成，Tab 顺序与视觉顺序一致。
- [ ] 聚焦状态可见；对话框打开后焦点进入，关闭后回到触发控件；没有焦点陷阱。
- [ ] 控件有可理解的可访问名称，图标按钮有 Tooltip 或屏幕阅读器标签。
- [ ] 颜色不是唯一状态信号；文本与背景至少达到 WCAG AA 对比度目标。
- [ ] 表格有表头语义，表单字段有 label，错误与字段关联。

## 数据与安全

- [ ] 401、403、429、5xx、超时和网络中断都有可操作反馈。
- [ ] 前端不信任权限隐藏；危险操作由服务端授权并记录审计。
- [ ] 生产数据已脱敏，日志、截图和 Prompt 不包含密钥、个人敏感信息或客户隐私。
- [ ] 部分失败不会误报为全量成功，重复提交不会产生重复业务动作。
